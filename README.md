# Fitness Club — نادي اللياقة البدنية

تطبيق لياقة عربي (RTL) لتتبع التمارين، أحد منتجات مركز الطلاب. التسجيل عبر
حساب مركز الطلاب فقط.

- `app/` — تطبيق Flutter (Android) — المنتج الأساسي. انظر `app/README.md`.
- `backend/` — الـ API (Next.js + Postgres/PGlite) وجسر تسجيل الدخول مع مركز
  الطلاب (`backend/hub-patch/` للملفات الخاصة بريبو مركز الطلاب)، بالإضافة
  لنسخة ويب مرجعية بنفس الشاشات.

الحالة: التطبيق جاهز للمراجعة محليًا؛ النشر (Vercel/Neon + متجر) يأتي لاحقًا.
